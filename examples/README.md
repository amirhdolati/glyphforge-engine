## Moving-camera 3D examples

- `python -m examples.orbit_camera`: orbit a stationary robot sculpture; see its front, back, sides and top.
- `python -m examples.dolly_camera`: move around a fixed arrangement of pillars to reveal parallax and depth occlusion.

Both use `MeshEngine` and `look_at`; model geometry does not animate. [Camera tutorial](../docs/cameras.md).

## Vaporwave 3D scene

`python -m examples.vaporwave` renders a striped sunset behind 3D wireframe mountains and a perspective neon floor grid. Its camera drifts gently to show parallax. Export a still with `python -m examples.vaporwave --output output/vaporwave.html`.

## Shared options

| Option | Default | Meaning |
| --- | --- | --- |
| `--output PATH` | Live terminal | Export `.html`, `.svg`, `.ans`, or `.txt` and exit |
| `--width N` | 100 | Maximum character columns |
| `--height N` | 36 | Maximum character rows |
| `--time SECONDS` | 1.0 | Animation time for an exported still |
| `--fps N` | 24 | Target live frame rate, not a performance guarantee |
| `--256` | Auto-detection | Force xterm-256 color in the live terminal |

Quit with Q, X, Escape or Ctrl-C. The demos animate the camera or object automatically; they do not implement walking. The shared runner adapts to terminal resizing. Offline exports always use the requested dimensions; `--256` affects live output only.

```sh
python -m examples.night_rain --output output/night.html
python -m examples.rotating_cube --width 80 --height 28 --time 2 --output output/cube.svg
python -m examples.hello_terminal --output output/waves.ans
```

The bundled pyramid geometry and palette were authored for this repository. Scenes and demo assets stay outside the installed Python package. Clone the repository to use them.

## Reproduce the gallery

```sh
python -m pip install Pillow
PYTHONPATH=src:. python tools/render_gallery.py
```

This creates 29 PNGs, 29 SVGs, and twelve GIFs under `docs/images`. All are derived from real rendered frames. The donation QR is the original owner-supplied asset and is not generated by this tool.

To regenerate only selected previews:

```sh
PYTHONPATH=src:. python tools/render_gallery.py --only spacecraft_flyby solar_orrery
```
